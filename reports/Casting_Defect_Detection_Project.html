Casting Defect Detection using a Fine-Tuned Vision-Language Model

Kushneet Kaur  ·  B.Tech CSE, MAIT  ·  August 2026  ·  Base-vs-fine-tuned study on Qwen/Qwen3-VL-4B-Instruct

1. Aim

To measure how well a pretrained vision-language model detects casting defects before any training, and how much task-specific fine-tuning changes that — with the base model measured first, and the fine-tuned model evaluated on exactly the same images with exactly the same prompts, so the difference is attributable to fine-tuning alone.

4. Mechanism

UPLOAD CASTING IMAGE → VISION-LANGUAGE MODEL → parse structured reply →
   TRACK A (primary): Is the casting defective? → OK / Defective
   TRACK B (secondary): which of the 12 defect types? → label or "Unmatched"
   → model-reported confidence + visual evidence

The model receives one image plus one of three fixed prompts and replies in a structured format, parsed into a verdict, defect type, confidence and justification. Fine-tuning teaches that verdict from the dataset's own ground-truth labels — no label is invented.

5. What was done

  • Dataset audit. Every count and dimension measured from the files themselves; verified byte-identical to the authentic Kaggle archive by checksum.
  • Leakage prevention. Filenames carry no source-casting identity (index-match rate 2.9% = chance), yet 360 cross-class pairs exceed 0.99 similarity — the same casting reused across classes. Images are therefore grouped by visual content into 854 groups, each assigned wholly to one split. Verified: worst cross-split similarity 0.9491, zero groups spanning splits.
  • Frozen evaluation. 178 held-out test images × 3 fixed prompts = 534 generations, locked to disk so the base and fine-tuned runs see identical inputs. Greedy decoding, seed 42. Nine run settings plus the full decoding config are asserted equal across the two runs before any comparison is accepted.
  • Two-track scoring. Track A on a class-balanced 12 OK + 12 Defective slice; Track B on all 178 images across the 12 original labels.
  • Engineering. 166 automated tests; the training script refuses to run before a baseline exists; the comparison script aborts if the two runs differ in even one image.

The two accuracy rows are the same behaviour seen from two angles. The fine-tuned model answers "Defective" almost unconditionally: it catches every defect in the balanced slice and recognises only 6 of 36 OK rows. A test set that is 93% Defective rewards that; a balanced one does not. The +0.2846 figure must not be quoted without the −0.1528 beside it. The cause is identifiable: the training split is 767 Defective vs 71 OK (91.5% Defective), and no class-balanced sampling or loss weighting was applied. All 24 regressions are OK castings, and none are Defective — the signature of a learned base rate rather than a learned feature.

9. Honest limitations

The defect classes in this dataset are synthetic — generated by a script that paints defect textures onto real defect-free castings. Results therefore describe detection of synthetic defect patterns, and do not demonstrate recognition of real industrial casting defects. Validation on genuine defect photographs remains future work.
  • Only 12 OK images reach the test set, so OK-class recall carries wide error bars (Wilson 95% CI on the base model's OK recall: 0.468–0.911) and is reported as indicative.
  • The 91.5% Defective training split was not corrected for; class-balanced sampling, loss weighting or a calibrated decision threshold are the obvious next steps.
  • Confidence values are the model's own self-reported numbers, not calibrated probabilities — one wrong answer was stated at 100% confidence.
  • Single random seed; no confidence intervals across repeated runs.
  • A conventional CNN would likely be stronger and cheaper here; the VLM is studied because the task is a before/after fine-tuning comparison, not a search for peak accuracy.
  • Research prototype only — not a certified industrial quality-control system.
